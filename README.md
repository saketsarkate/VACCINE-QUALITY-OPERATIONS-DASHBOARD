# VACCINE-QUALITY-OPERATIONS-DASHBOARD
  A ready-to-use synthetic dataset covering multiple aspects of pharmaceutical vaccine quality, manufacturing, batch release, deviations, CAPA, QC, and complaint reporting. 
 
Data status:	
  All the records are synthetically created (randomly generated) for learning purposes by me and to show the demonstration of the dashboard preparation.

Used workflow:	
  Product → Batch → Manufacturing → QC → Release → Deviation/CAPA → Complaint

What I used?:	 
  Excel Tables, XLOOKUP, SUMIFS, COUNTIFS, PivotTables, PivotCharts, Slicers, Conditional Formatting.

Dashboard goal:	
  Track batch volume, release performance, quality trends, deviations, CAPA, complaints and how the comlaints are handled and solved effectively. Also, the duration can be monitored.
